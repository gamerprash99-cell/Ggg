## 3. What Works Right Now (Ready for Testing)

A user installing the debug APK generated by the project can:
1. Open the app and immediately see pre-seeded sample data demonstrating active habits, tasks, and notes.
2. Create, pin, edit, and organize notes into folders.
3. Use the AI tool inside notes to extract action items directly into the task manager.
4. Check off tasks and watch the home progress circle update immediately.
5. Log expenses and view spending breakdowns in the Insights screen.
6. Write diary entries and review their life narrative in the chronological Timeline.
7. Chat with LifeOS AI locally to ask questions about tasks and spending.
8. Export their entire database to a JSON file and restore it on demand.
